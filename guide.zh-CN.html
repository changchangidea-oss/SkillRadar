SKILLRADAR 中文说明

先找到真正匹配的 Skill，
再让 Codex 开始工作。

SkillRadar 是一个开源的 Agent Skills 发现、审查与任务路由工具。你可以直接用中文描述开发任务，它会从经过安全门过滤的离线 Registry 中返回最多 3 个有明确证据的候选，而不是用无关 Skill 凑数。

打开在线路由器 查看 GitHub ↗
在线体验

三步得到可审查的匹配结果

01

描述具体任务

在 Skill Router 输入中文或英文任务。技术栈、工具和目标越明确，匹配越可靠。

检查 Supabase RLS 权限并优化查询性能
02

查看 Top 3 与证据

结果综合任务相关性、候选自身证据、安全、质量和维护情况。找不到足够专用的能力时，会明确显示能力缺口。

03

审查后再安装

查看上游 SKILL.md、安全等级和来源，再复制精确安装命令。发现结果不会自动执行第三方代码。

可以直接试： 为 Node API 增加 Redis 缓存 构建 Next.js App Router AI 仪表盘 为品牌设计中文活动海报
安装方式

同一仓库，两种使用路径

推荐 · CODEX PLUGIN

在 Codex 中直接路由

使用随插件打包的离线 Registry，以及 $skill-router、$find-skill、$inspect-skill 和 $manage-skills。

codex plugin marketplace add changchangidea-oss/SkillRadar --ref v0.5.0
codex plugin add skillradar@skillradar
STANDARD AGENT SKILL

安装标准 Agent Skill

适合兼容开放 Skills 生态的 Agent。它提供先阅读、再发现的工作流，不会自动授权候选 Skill 执行。

npx skills add changchangidea-oss/SkillRadar --skill skillradar

安装后怎么问

  • $skill-router 为 FastAPI 服务设计 webhook 处理流程
  • $find-skill 找一个适合 Flutter 移动端开发的 Skill
  • $inspect-skill 检查这个候选的来源和安全风险
  • $manage-skills 检查当前 Skill 是否过多或重复
如何看结果

安全等级是筛选信号，不是执行许可

A

低风险静态特征

仍应在实际使用前阅读 Skill 内容。

B

有限副作用或包含脚本

执行前确认脚本行为和所需权限。

C

需要明确人工审查

重点检查 shell、网络、文件写入、依赖安装等能力。

D / Blocked

不进入自动路由

只保留审计证据，不能作为自动推荐结果。

重要边界：发现 ≠ 执行。

安装 SkillRadar 不代表允许第三方 Skill 访问密钥、运行 shell、修改数据库、部署服务或访问外部网络。此类操作仍需单独审查和明确授权。

常见问题

在线页面会做什么？

在线体验会运行候选 Skill 吗？

不会。浏览器只读取经过安全门过滤的静态 Registry，并进行本地匹配和展示。

为什么有时不到 3 个结果？

这表示没有足够多且具有明确任务证据的安全候选。SkillRadar 会诚实显示能力缺口，不用泛化 Skill 补满 Top 3。

排名只看 GitHub Stars 吗？

不只看 Stars。匹配会综合具体任务证据、质量、安全、兼容性与维护信号；流行度不能替代相关性。
