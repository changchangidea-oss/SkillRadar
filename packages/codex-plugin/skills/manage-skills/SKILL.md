# Manage Skills

Use SkillRadar to keep the active skill set small.

## Rules
- Prefer global installation only for broadly reusable capabilities.
- Prefer project scope for stack-specific or discipline-specific skills.
- Avoid keeping near-duplicate skills active when one strong skill covers the same task.
- Design-specialty skills such as Remotion, Blender, OpenSCAD, fashion campaign, architecture visualization, or typography should normally be project-scoped unless used across many projects.
- Use `find-skill` before adding a new capability and `inspect-skill` before trusting third-party scripts.
- Discovery does not authorize execution.
